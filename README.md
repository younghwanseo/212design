# 212 DESIGN — 홈페이지

서울 기반 시각 디자인 스튜디오 212디자인의 공식 홈페이지입니다.
빌드 도구 없이 동작하는 정적 사이트라, `index.html`을 더블클릭하면 바로 열립니다.

## 폴더 구조

```
homepage/
├── index.html          홈
├── about.html          회사소개
├── team.html           팀원소개
├── work.html           작업물 목록 (분야 필터)
├── project.html        작업물 상세 — ?id=프로젝트아이디 로 열립니다
├── data/
│   ├── projects.js     ← 작업물을 추가·수정하는 곳
│   └── team.js         ← 팀원, 회사 연락처를 수정하는 곳
├── assets/
│   ├── css/style.css   디자인 시스템 (색·타이포·간격 토큰이 맨 위에 있습니다)
│   ├── js/site.js      데이터를 읽어 화면을 그리는 스크립트
│   └── img/
│       ├── work/       작업물 이미지
│       ├── team/       팀원 사진
│       └── favicon.svg
└── README.md
```

## 작업물 추가하기 (팀원용)

1. 이미지를 `assets/img/work/` 폴더에 넣습니다.
   - 권장: 가로형 16:11 비율, 가로 1600px 이상, JPG 또는 WebP
   - 파일 이름은 영문 소문자와 하이픈만 사용해 주세요. 예: `hansol-brand-01.jpg`
2. `data/projects.js`를 열고, 기존 항목 하나를 통째로 복사해 맨 위에 붙여넣습니다.
3. 값만 바꿉니다.

```js
{
  id: "hansol-brand",          // 주소에 쓰이는 고유값. 영문·하이픈만, 중복 금지
  code: "BR/26-02",            // 내부 관리 번호 (자유 형식)
  title: "한솔 브랜딩",         // 한글 제목
  titleEn: "HANSOL Branding",
  category: "Branding",        // Branding / Editorial / Package / Exhibition / Digital
  categoryKo: "브랜딩",         // 필터 버튼에 표시될 이름
  client: "한솔",
  year: "2026",
  role: "브랜드 아이덴티티 · 인쇄물",
  summary: "카드와 목록에 쓰이는 한 줄 요약입니다.",
  description: ["첫 번째 문단", "두 번째 문단"],   // 원하는 만큼 추가 가능
  credits: [["Creative Direction", "김서연"]],     // [역할, 이름] 쌍
  cover: "assets/img/work/hansol-01.jpg",          // 대표 이미지
  images: ["assets/img/work/hansol-01.jpg",
           "assets/img/work/hansol-02.jpg"],       // 상세 페이지 이미지들
  featured: false              // true 로 두면 홈 '최근 작업'에 노출됩니다 (3개 권장)
}
```

4. 저장하고 브라우저를 새로고침하면 목록·필터·상세 페이지가 자동으로 만들어집니다.

> 홈 첫 화면의 큰 이미지는 `data/projects.js`에 적힌 **순서대로** 전체 작업물을 5초마다 자동으로 넘겨 보여줍니다.
> 좌·우 화살표, 키보드 ←→, 모바일 스와이프로 직접 넘길 수도 있고 마지막에서 다시 처음으로 돌아옵니다.
> 맨 앞에 두고 싶은 작업물을 목록 맨 위로 옮겨 주세요. 슬라이드에는 각 항목의 `cover` 이미지가 쓰입니다.
>
> 넘어가는 속도는 `assets/js/site.js` 맨 위쪽 `HERO_AUTOPLAY_MS = 5000` (밀리초)에서 바꿉니다.
> 마우스를 올렸거나 화면 밖으로 스크롤했거나 다른 탭을 보고 있으면 저절로 멈추고,
> 캡션 오른쪽 `PAUSE` 를 누르면 완전히 멈춥니다. 움직임을 줄이는 운영체제 설정에서는 처음부터 자동 재생하지 않습니다.

> 마지막 항목 뒤에는 쉼표를 붙이지 마세요. 화면이 비어 보이면 대부분 쉼표나 따옴표 문제입니다.
> 브라우저에서 F12 → Console 탭을 열면 어느 줄이 문제인지 알려줍니다.

## 팀원 · 회사 정보 수정하기

`data/team.js` 한 파일에서 모두 관리합니다.

- `window.TEAM` — 팀원 목록. 사진은 `assets/img/team/`에 3:4 비율로 넣어 주세요.
- `window.SITE` — 회사명, 이메일, 전화, 주소, 인스타그램 주소. 여기만 고치면 모든 페이지의 푸터가 함께 바뀝니다.

## 디자인 수정하기

`assets/css/style.css` 맨 위 `:root` 블록에 색·서체·간격이 모여 있습니다.

| 변수 | 용도 |
|---|---|
| `--paper` | 페이지 바탕색 |
| `--ink` | 본문 글자색 |
| `--line` | 구분선 |
| `--gutter` | 좌우 여백 |
| `--maxw` | 콘텐츠 최대 너비 |
| `--hero-ar` | 홈 첫 화면 이미지 칸의 비율 (기본 `16 / 11`) |

> 첫 화면의 세로 높이는 **창 높이가 아니라 `--hero-ar`** 가 정합니다.
> 그래서 브라우저 창을 위아래로 늘였다 줄여도 이미지 배율과 제품 위치가 전혀 변하지 않습니다.
> 작업물 이미지 비율을 16:11이 아닌 값으로 바꾸신다면 이 값도 함께 고쳐 주세요 —
> 두 값이 같아야 이미지가 잘리지 않고 꼭 맞게 들어갑니다.
>
> 첫 화면을 더 높게 쓰고 싶으시면 세로가 긴 비율(예: `4 / 3`)로 바꾸고
> 이미지도 같은 비율로 준비하시면 됩니다.

작업물이 주인공이 되도록 채도가 있는 색은 쓰지 않았습니다.
브랜드 컬러를 넣으실 경우 버튼·링크 등 아주 작은 면적에만 쓰시길 권합니다.

## 인터넷에 올리기

정적 파일이라 아래 방법 모두 무료로 가능합니다.

- **Netlify** — netlify.com 접속 후 이 폴더를 통째로 드래그 앤 드롭
- **Vercel** — 폴더를 GitHub에 올린 뒤 저장소 연결
- **GitHub Pages** — 저장소에 올리고 Settings → Pages에서 브랜치 지정
- **일반 웹호스팅** — FTP로 폴더 내용을 그대로 업로드

도메인(예: 212design.kr)은 위 서비스의 도메인 설정에서 연결하시면 됩니다.
